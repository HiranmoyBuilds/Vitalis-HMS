The Hospital Management System (HMS) is a comprehensive web-based platform built with the MERN stack (MongoDB, Express.js, React, Node.js) and Vite, designed to digitize and streamline hospital operations. It offers separate portals for patients and administrators with dedicated login pages. Patients can self-onboard, book appointments, access health records, attend video consultations, pay bills online, and communicate with support via real-time chat. Administrators benefit from analytics dashboards, inventory management, user oversight, billing reconciliation, and a support desk module. The system integrates MongoDB Atlas for cloud database management, Socket.io for real-time messaging, and third-party APIs for payments and video calls, providing a scalable, secure, and user-friendly solution for modern healthcare facilities.
